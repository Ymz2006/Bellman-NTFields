On 22×22, true speed rows are {{dtruezero22}} points against empty rows, lower on {{ltruezero22}} seeds ({{seedstruezero22}}). They are {{dtrueflip22}} points against flipped rows ({{seedstrueflip22}}). So the real walls cost more than walls in the wrong place. Exact speed gives the same picture more clearly: {{doraclezero22}} against empty, and {{doracletf22}} against flipped, lower on {{loracletf22}} seeds. The exact rows also carry heading, which the line rows do not, so this is not a limit of the line fit.

On 13×13 the differences are small: {{zero13}} % empty, {{flip13}} % flipped, {{true13}} % true. True rows are below flipped on {{ltrueflip13}} seeds ({{dtrueflip13}} points), but this maze is near its ceiling and seeds move by several points.
