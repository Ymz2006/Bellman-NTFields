Octave Row Visualizer

A point is q = (x, y, φ), with x and y running from −0.5 to 0.5 across the maze. The network never sees q itself. It sees sin and cos of 2π b·q for 128 rows b, so each row is a plane wave over the maze. The grid-synced octaves keep each row's random direction and set its length so the wave flips sign every L cells along its main axis. The grid-anchored rows go one step further and make the wave start and end on grid lines.
