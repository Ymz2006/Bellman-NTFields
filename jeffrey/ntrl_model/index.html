The ntrl-demo metric network

One network takes a start and a goal and returns the travel time T between them. It never outputs speed directly. Speed is read off the gradient as S = 1/|∇T|, and the planner moves the start downhill on T towards the goal. This is the field behind every ntrl-demo result in the maze, cabinet and two-cube runs.

How it is trained

Each training row is a pair of poses with their target speeds S₀, S₁ and the unit clearance gradients n₀, n₁ (pointing away from the nearest obstacle). Every term below is computed at both ends of the pair.

  • eikonal · weight 10⁻²(√(S · |∇T|) − 1)²Makes the slope of T match one over the target speed.
  • TD · weight 10⁻³( T(x₀, x₁) − [ T(x₀′, x₁) + 0.03/S ] )², x₀′ = x₀ − 0.03 · S · ∇ₓ₀TTake one short step downhill; T here should equal the step's time plus T from where it lands. The bracket is held fixed (no gradient), and the term is skipped when T is shorter than one step.
  • normal (the wall term) · weight 10⁻³(1.001 − S) · |S · ∇T + n|²Only acts where S is small, next to obstacles. It makes T rise steeply going into the obstacle, which pushes the planner away from it.

The sum is multiplied by exp(−0.5 · T), with gradient flowing through T, then averaged over the batch. Far pairs therefore count less. The network can also lower this loss by making T larger everywhere, which is how the strong-cabinet trainings collapsed to slow everywhere.

Other details of the trainer: target speeds are stretched first, s ← s²(2 − s)², then α·s + 1 − α. The optimiser is AdamW with learning rate 5·10⁻⁴ and weight decay 0.5, in 5,000 epochs of 5 batches of 2,000 pairs. Each epoch's loss is rescaled by one over the previous epoch's loss. If an epoch's loss rises more than 1.2×, a random one of the last five saved states is reloaded and the epoch is repeated.

What limits sharp walls

  1. Sharp changes have few places to come from. Every linear layer is clamped to be smooth, so steep features come from the 128 fixed frequencies in B and from the u·sin y products. Rescaling the input (the maze zoom control, the same as scaling B) recovered a lot at 13×13: 444 vs 347 of 600.
  2. One embedding sets every distance. The same 256 numbers per pose decide both the wall barrier nearby and the travel time to far goals. More walls share the same capacity. At 40×40, the field's direction next to a wall matched "away from the wall" with cosine 0.07–0.10, against 0.98 at small sizes.
  3. The slowest speed is capped. The per-row normalisation and the fixed 0.2 factor bound |∇T|, so there is a limit on how slow the field can make the space next to an obstacle.
  4. Far pairs get less training signal. The exp(−0.5·T) weight shrinks the loss for long pairs, so long-range accuracy is learned more weakly than short-range accuracy.
