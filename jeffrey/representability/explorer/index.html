How the values are computed

The trained line is x(s) = x* + s·u in release units (joint angle divided by its range: 12.57 rad for five joints, 6.28 rad for the elbow), with x* the middle-compartment pose and u the least-norm IK joint direction that moves the gripper in +y, scaled to unit length. Along it the gripper travels 6.2 m per unit of s, so the line spans about ±31 cm. The single-joint axes are scaled the same way: one release unit is 12.57 rad (6.28 rad for J3), so ±0.05 is ±0.63 rad (±0.31 rad).

Truth: the clearance label d of the arm against the slab (and the arm's own self distance), the trained target speed s′(d) = 1.025 S²(2 − S)² − 0.025 with S = clip(d, 5 mm, 5 cm) / 5 cm, and the travel time by integrating 1/s′ along the axis from the picked point. On the trained line this is the exact 1-D answer the networks were trained toward. Along a single joint it is the time for moving that joint alone, which is an upper bound: the true 6-D shortest time can be lower by using other joints.

Networks: ntrl-demo's metric network with its own loss (base), with the log eikonal loss (log), and with the embedding stretched 5× (metric factor 1 instead of 0.2, "stretch"), trained for 4,000 updates of 2,000 pairs; the original method's TravelCost with the eikonal loss (TravelCost) and with ntrl-demo's direction term added at weight 1 (TravelCost + direction), 15,620 updates of 256 pairs. Each family is retrained here with the line test's seed; the line models reproduce the reported table. Line data: pairs with both ends on the line, s ∈ [−0.05, 0.05]. Tube data: each end moved off the line by up to 0.02 release units in a random direction orthogonal to u. Shaded grey: points the training data never reached.
